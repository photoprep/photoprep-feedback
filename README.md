# photoprep feedback

Bug reports and ideas for photoprep, sent from the app or filed here.
The easiest way to report is the app's Help menu: Report a bug or Suggest a feature.
Each report is an issue here; ideas can be voted on with a thumbs-up.
Logs and any files you choose to attach are kept in a private repository, never on the issue.
Bundles are deleted 90 days after their issue is closed.
